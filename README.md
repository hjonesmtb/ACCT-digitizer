# Target-Protect-Firmware
Firmware for the FPGA on the DE10-Nano for the BL1A Target Protect Monitor. This is a Quartus Prime
18 project for the DE10-Nano Board which is used as the controller for the interlock. This project 
is based upon the DE10-Nano Soc GHRD (Golden Hardware Reference Design), which provides default
configurations with an enabled HPS connected to the FPGA fabric.
